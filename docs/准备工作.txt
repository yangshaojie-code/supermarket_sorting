📋 准备工作：更新系统并确认 GPU
在开始前，先确保系统是最新的，并确认 NVIDIA GPU 已被识别。
确定电脑剩余可用空间>100G

bash
# 1. 更新软件包列表和系统
sudo apt update
sudo apt upgrade -y

# 2. 查看是否已识别 NVIDIA 显卡
lspci | grep -i nvidia
如果命令有输出，说明硬件已被识别。

1. 🐳 安装 Docker
推荐使用 Docker 官方脚本进行安装，这是最简单的方式。

bash
# 1. 下载并执行 Docker 官方安装脚本
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 2. 启动 Docker 服务并设置开机自启
sudo systemctl start docker
sudo systemctl enable docker

# 3. 将当前用户加入 docker 组，避免每次使用都需要 sudo
sudo usermod -aG docker $USER

# 4. 重启系统或重新登录，使组权限生效
# 可以执行 newgrp docker 或直接重启
注意：官方建议从 Docker 官网安装，以避免 Ubuntu 仓库中 docker.io 版本较旧的问题。为了确保镜像拉取速度，可以考虑配置国内镜像源。

2. 🚀 安装 NVIDIA 显卡驱动
这一步是让系统能识别并使用 NVIDIA GPU。最稳妥的方式是使用 Ubuntu 的 ubuntu-drivers 工具自动安装推荐的驱动版本。

首先，添加 NVIDIA 驱动仓库（非必需，但推荐）：

bash
sudo add-apt-repository ppa:graphics-drivers/ppa
sudo apt update
查看推荐的驱动版本并安装：

bash
# 查看推荐的驱动版本
ubuntu-drivers devices
# 自动安装推荐的驱动
sudo ubuntu-drivers autoinstall
如果 autoinstall 无效，可以手动指定版本安装，例如 sudo apt install nvidia-driver-550。

重启系统以加载驱动：

bash
sudo reboot
验证驱动是否安装成功：

bash
nvidia-smi
如果能看到 GPU 信息列表和驱动版本号，则说明驱动安装成功。

3. 🧰 安装 NVIDIA Container Toolkit
这个工具让 Docker 容器能够访问宿主机的 NVIDIA GPU。

bash
# 1. 配置 NVIDIA 官方软件源
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg \
  && curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

# 2. 更新软件包列表并安装
sudo apt update
sudo apt-get install -y nvidia-container-toolkit

# 3. 配置 Docker 使用 NVIDIA 运行时
sudo nvidia-ctk runtime configure --runtime=docker

# 4. 重启 Docker 服务
sudo systemctl restart docker
注意：以上命令参考了 NVIDIA 官方文档。如果安装失败，可能是网络问题，可以尝试更换软件源或检查网络连接。

✅ 4. 验证整个环境
执行一个测试命令，验证 Docker 是否能成功调用 GPU。

bash
docker run --rm --gpus all nvidia/cuda:12.2.0-base-ubuntu22.04 nvidia-smi
如果能在容器内正确显示 nvidia-smi 的输出，说明所有组件都已配置成功。
